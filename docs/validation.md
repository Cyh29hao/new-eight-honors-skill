## 使用者可自行检查

1. 在临时项目保留一段自己的 `AGENTS.md` 内容，运行命令，核对原文、备份和一个新标记块。
2. 再运行一次，确认不重复追加；`--dry-run` 不应写任何文件。
3. 新会话用 `$eight-honors`，确认实际读取的路径。
4. 给一个真实小任务，看交付是否先说结果与缺口，再解释八条体现。
5. 长任务另查额度和交接；自动恢复必须有真实宿主调度与触发证据。
