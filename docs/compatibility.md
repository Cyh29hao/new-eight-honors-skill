# 能力与型号怎么选

这套约定需要模型能理解目标、遵循规则，并使用宿主给它的工具。越涉及长任务、真实文件和多次修订，越需要稳定的判断与工具调用能力。

| 工作环境 | 能用到什么 |
| --- | --- |
| 只有文本聊天 | 借用八条组织回答；文件验收、安装和额度工具仍需实际工具。 |
| 能读写文件、运行命令的 Codex | 使用完整 skill、项目 AGENTS.md，以及安装和交接工具。 |
| 另有图片查看或浏览器能力 | 可以对照实际页面、图片和文档做视觉验收。 |
| 已登录、支持 App Server 的 Codex CLI | 可以运行随包的真实额度查询。 |
| 有持久状态、宿主调度与相应授权 | 可以另行安排并验证自动接续；安装 skill 本身不创建调度。 |

## Codex 型号

按 2026-10-29 查阅的 [OpenAI 官方型号说明](https://learn.chatgpt.com/docs/models)和[选型说明](https://learn.chatgpt.com/docs/model-selection)：

- **GPT-6.1 Sol**：可先用于常规的复杂、多轮项目。
- **GPT-6 Astra**：可考虑用于更难的分析、判断和完整交付。
- **GPT-6.1 Terra**：可考虑用于写作、视觉理解和应用操作。
- **GPT-6 Luna**：可先试范围明确、可直接检查的小任务。

这些是按官方任务定位给出的起点，不是本 skill 的跨型号效果评测。使用你账户实际可用的型号，用熟悉任务比较结果，不为了使用八条就默认切到最贵或最高推理档。

## 其他宿主

安装器的 `--agent claude` 使用项目 `.claude/skills/eight-honors` 与 `CLAUDE.md`。文件行为可测试，实际 Claude Code 会话加载仍须用你的客户端核对。其他支持 Agent Skills 的宿主按自己的加载目录使用 `SKILL.md`。

所有宿主都可以调整报告频率和语气。Codex 额度接口只适用于对应 CLI，不能当作其他模型服务的额度来源。
